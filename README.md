# 🔐 Python Authentication System

A secure and lightweight **User Authentication Web Application** built with **Python and Flask**. This project provides a complete authentication workflow including user registration, login, password protection, JWT-based authentication, and protected routes.

## 🚀 Features

- 👤 User registration
- 🔑 User login
- 🔐 Password hashing and secure storage
- 🎟️ JWT-based authentication
- 🛡️ Protected routes
- 🚪 Logout functionality
- ✅ User authentication validation
- 💾 Database-based user management
- 🌐 Flask web interface

## 🛠️ Tech Stack

- Python
- Flask
- JWT / PyJWT
- SQLite
- HTML5
- CSS3
- Jinja2

## 🎯 Purpose

This project was developed to understand how authentication systems work in web applications, including user management, password security, token-based authentication, and protected API/web routes.

## 📚 Learning Outcomes

- Flask authentication
- JWT implementation
- Password hashing
- Session and token management
- Database operations
- Protected routes
- Backend security concepts
